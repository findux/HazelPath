# HazelPath

NC/G-code editing and toolpath visualization application built with openFrameworks.

## Build

The project uses Visual Studio on Windows and must be placed under
`apps/myApps/` in an openFrameworks checkout. Install the addons listed in
`addons.make`, then open `NC_kod_duzeltici.sln` and build the x64 configuration.
Machine definitions and import/export scripts are in `bin/data/machines/`.
